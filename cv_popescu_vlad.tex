\project{PoliTCP}{C++, C, Make, Git, GitHub, Linux}{%
\begin{itemize}
  \item \textbf{Protocol Design:} Custom reliable transport protocol over raw UDP sockets, replicating core TCP mechanisms (sliding window, flow control, ordered delivery) at the application layer via the POSIX API.
  \item \textbf{Flow Control:} Bidirectional sliding window on both sender and receiver sides, with BDP-aware window sizing to maximise link utilisation.
  \item \textbf{Reliability:} Guaranteed in-order, duplicate-free delivery through cumulative ACKs, retransmission logic, and out-of-order segment buffering.
  \item \textbf{Concurrency:} Background POSIX threads handle ACK processing and retransmissions independently, protected by per-connection mutexes.
\end{itemize}}
